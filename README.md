# horizon-site

The public site for **Horizon**, a net-worth projection app for Android.

Jekyll on GitHub Pages, using the `minima` theme, same as
[runway-site](https://github.com/rglarson13/runway-site) -- these are sister
apps and the sites are deliberately built the same way.

Published at <https://rglarson13.github.io/horizon-site/>.

`privacy-policy.md` is the page Google Play requires. Its URL is entered in the
Play Console listing, so **the filename must not change** once the app is
submitted.
